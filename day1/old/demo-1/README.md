## 실행 환경 (택1)
- **Google Colab (권장)**: `.ipynb` 파일 업로드 → 런타임 > 모두 실행. 설치 불필요.
- **로컬**: `pip install -r requirements.txt` → `jupyter notebook`
- 데이터는 scikit-learn 내장 데이터(`digits`)와 합성 데이터만 사용 → **인터넷 없이 동작**, 각 노트북 실행 1분 이내.
- 노트북은 **실행 결과가 저장된 상태**로 제공됩니다. 강의실에서 실행이 안 되면 저장된 출력으로 바로 설명할 수 있습니다.
- `random_state`가 고정되어 있어 슬라이드의 수치와 같은 결과가 재현됩니다.

## 변형 실험 (시간 여유 시 / 학생 과제)
- Demo 1: `EPS` 값 변경, `squeeze(levels=2)`로 바꿔 탐지율과 오탐률의 트레이드오프 확인
- Demo 2: `FRAC=0.6`으로 표적 오염 비율을 높이면 kNN 정제가 **실패**함 (과반 오염 시 다수결 붕괴). 트리거 위치·크기 변경
- Demo 3: 정규화 강도(`max_depth`, `min_samples_leaf`) 변경 → train/test 격차와 MIA AUC의 관계 확인, 질의 예산(`budgets`) 변경
